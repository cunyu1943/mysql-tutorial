# MySQL 学习指南

一个面向初学者与进阶用户的 MySQL 学习教程，提供从基础概念到 SQL 实战的系统化学习路径。

## 一、内容模块

### 1.1 基础教程

面向零基础读者，从数据库基本概念入手，讲解 MySQL 的安装配置与日常操作，帮助读者快速搭建学习环境并完成第一次数据库操作。

- [快速入门](docs/src/basic/20210623-quick-start.md) — 数据库基本概念、常见数据库软件、MySQL 安装与基础操作
- [开发环境搭建](docs/src/basic/20240314-environment.md) — MySQL 开发环境配置详解

### 1.2 SQL 必知必会

基于《SQL 必知必会》练习题的全解析，共 50 道题目，分为 10 个部分。内容由浅入深，涵盖数据的排序、过滤与分组，以及表、视图、联结、子查询、游标、存储过程和触发器等进阶知识点，适合在掌握基础后进行巩固与提升。
